# Courier Route Bot

Telegram-бот для автоматического создания ежедневного маршрута курьера по фотографии маршрутного листа.

## Цель

- получить фотографию таблицы в Telegram;
- извлечь адреса строго сверху вниз;
- определить тип точки по цвету строки: INVITRO / CMD / другая лаборатория;
- нормализовать адрес для поиска в Яндекс Картах;
- сравнить маршрут с базой известных адресов и предыдущим днём;
- показать последовательный маршрут с кнопками открытия Яндекс Карт;
- хранить одноразовые заметки: расходники, документы и другие действия;
- позволять добавлять дополнительные точки в течение дня.

Проект находится в активной разработке.
